# 验证记录

## 可复现检查

在仓库根目录运行：

```bash
npm run typecheck
npm run build
npm test
```

这些命令覆盖类型、生产构建和 Vitest 单元/集成/对抗测试。`npm run test:browser` 当前没有作者测试，不应作为已通过的浏览器结果。

上一轮构建（包含手动补助、居民追踪、共享车道与前后段缓冲）通过；针对 `grants`、`focus`、`shared-lanes` 的 12 项回归通过。安全缓冲子任务另外完成相关 34 项定向检查。此前共享车道阶段曾通过 93 项全套检查，但这些不是持续城市增长改动后的全套结果。

## 持续增长改动

- 本轮生产构建与类型检查通过；`city`、`city-growth`、`development-demand`、`grants`、`persistence`、`network`、`population` 共 38 项定向检查通过。
- 覆盖连续 10 轮超过旧 14 栋限制、地图扩大但旧位置不变、布局尺寸差异、基础设施与有效步行路径避让、有限岗位入住、暂停不补刷、旧完成存档恢复发展、中心权重与个体错峰、累计补助和扩图保存。
- 独立 `localhost` 页简检：住宅显示 24/48 与下一批住户时间；旧存档办公楼显示真实任职人数、已开放岗位、完整岗位容量与就业中心说明；地图阶段/中心标记可见，控制台无警告或错误。
- 按用户要求没有重新进行长时间试玩或 120 栋/1,200 人/160 Pod 满载验证，不把容量保护上限当作已保证的帧率或吞吐。

## 已验证边界

- 轨道/节点/对角交叉/泊位资源互斥、有限停车尾部、实体守恒、保存恢复、经济账本和增长逻辑。
- 生产容量比较：8 个同时需求在基线与扩容网络中的 Pod/步行分流（见 `docs/modules/capacity.md`）。
- 曾验证旧 14 栋、156 人、30 个已连接 Pod 的 3,600 模拟秒负荷夹具。它不代表持续增长版本的 120 栋/1,200 人/160 Pod 满载结果。
- 独立浏览器验收已观察到 UI 建设、可见乘客标记、连续移动、暂停保存/读取和增长至 14 栋/156 名居民。
- 浏览器已验证点击整段选中 23 小段，Command 追加到 28 小段、一次升级 28 小段（预算 6,391 → 6,111），Shift 跨路口连选扩展到 36 小段。
- 浏览器已验证选中高亮连续且无逐格圆点叠加；聚焦选中轨道时未再出现反馈截图中的巨大蓝圈。
- 建筑检查器已验证当前意图、真实已完成步行/Pod 分流、住宅 24 名居民的工作分布与可展开姓名名单；地图数量与面板一致。
- 批量拆除在独立 `localhost` 测试城市验收：7 段折线 + 4 段独立轨道；点击、Command 多选、V/X 切换保留选区、Alt 单格后 Shift 绕角连选均通过。确认前仍有 20 段轨道；一次确认后只剩原始 9 段，选区清空，预算 1,768 → 1,900，准确退回 132。未拆动玩家正在运行的 `127.0.0.1` 城市进行此项测试。
- 同一独立城市又验证检查器批量拆除 3 段，准确退款 36；对会切断周转泊位的两段拆除请求，界面保留两段选区并显示原因，轨道和预算均未改变。浏览器未报告错误或警告。

## 待补或明确不声称

本轮按用户要求不继续详细浏览器测试。已做的独立浏览器检查包括：铺轨候选合法为绿、穿楼为红，鼠标预览不扣钱或落轨；引导关闭后刷新仍保持关闭。居民室内/室外追踪与手动补助做必要逻辑回归，新增共享车道及安全缓冲做针对性检查。新规则下的长时间试玩留给用户，不把先前浏览器结果冒充本轮全面验收。

满负载城市的浏览器帧率、任意网络的长期交互仍待验收；导出下载需确认浏览器实际落盘。尚未证明任意网络无死锁、30 分钟人类可玩性、挑战失败流程、附近建筑平台接驳、编组或 3D。增长按时间推进，不能将其描述为稳定性门槛。

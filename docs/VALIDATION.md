## 边界与后续

- 当前是一张 33 栋建筑的固定地图、6 个阶段任务、最高 48 辆 Pod。还没有科技树、动态建筑生成、多容量 Pod、长期战役和自动破产救济；资金耗尽可从经营面板重开。
- 每段是直线，可以组合折线；还没有连续拖绘、曲线编辑、多步撤销。几何交叉不自动连接；需点击轨道吸附建立节点。立交的专门视觉表现待补。
- 汽车、公交、地铁是聚合的门到门基准，没有逐辆社会车辆或完整旧交通路网仿真。建筑内部停车、车辆准时执行仍为抽象。
- 旧实验 Python 与 TypeScript 的逐事件自动对照尚未建立。没有 300/1,000 辆、长期内存、移动触控和稳定 60 FPS 的验收结论。
- JSON 导入和本地恢复已在浏览器验证。导出按钮已触发本地保存，但当前内置浏览器没有返回下载完成事件，因此未将“文件已落到 Downloads”标记为通过。
- 生产包存在一个超过 500 kB 的压缩前 JS chunk 提示；构建成功，后续可再拆分渲染依赖。

# 路网模块

`src/network/index.ts` 是纯读取的网格几何与寻路层，不提交建设、不扣款，也不修改 `World`。

- `tracePolyline` 用 Bresenham 栅格化把整数控制点展开为相邻的八方向固定单元。`validateTrackDraft` 拒绝浮点、越界、建筑占地和任何泊位点；草稿内重复单元及已建单元会去重，只有新增单元按实际长度计费。
- `edgeKey` 与 `nodeKey` 是方向无关的稳定预约资源。斜向边额外占用以两倍中点坐标命名的 `crossing`，同一格内两条相交对角线因此互斥，但不会在拓扑上自动连通。
- `findTrackPath` 将所有 `berth.point ↔ berth.access` 支路自动加入已建轨道图。泊位点可作为起点或终点，其他泊位点绝不会成为中途节点。
- `findWalkPath` 在地图内执行八方向 A*，建筑的闭区间网格占地不可进入；斜走时两个相邻正交点都必须可走，不能切建筑角。
- `buildingDoor` 返回建筑南侧、紧邻占地边界之外的中间整数点。调用方仍需结合地图边界和其他建筑检查该门是否可达。

边界约定：地图有效点为 `0 <= x < width`、`0 <= y < height`；所有网络与步行输入只接受有限整数。轨道几何交叉只共享预约资源，不自动产生节点。

# UI 模块

`src/ui/App.tsx` 编排界面，读取 `useSimulation()` 的可序列化 World 快照，只通过 `send(command)` 或 `replaceWorld(world)` 改变模拟。界面不生成虚假居民、Pod 或指标。

顶栏提供模拟时钟、暂停/恢复、1×/2×/4×速度、语言和设置；左侧提供查看、铺轨、拆除及生活/流量图层；地图是主要工作区，右侧检查器显示选中实体，底栏显示预算、服务占比、候车和步行统计。

铺轨工具用整数网格点生成草稿，持续显示实际段数、成本和校验错误。移动鼠标显示候选虚线及预计费用，合法为绿色、非法或超预算为红色；点击才固定候选端点。Enter/确认只提交已固定草稿，Backspace 撤销末点，Escape 取消；失败保留草稿。选择轨道时可选整段走廊，⌘/Ctrl 添加独立段，Shift 连选，Alt 只选单格；可批量升级到 2/3 条双向共享车道。

轨道拆除与查看共用选区，切换拆除工具不会丢失多选。拆除模式先选轨道，再用底部“确认拆除”一次提交；显示可拆段数与预计退款，不会点击一格就立即破坏网络。检查器的拆除按钮也作用于整个选区。已在排队改造的轨道不重复提交；实际执行后自动清理选区里的失效 ID，保留仍在排空的部分。

检查器展示真实的建筑住户/候车人、泊位队列与占用、居民家/工作/目标/方式/ETA、Pod 计划与最终泊位，以及轨道当前占用、预约和待拆状态。建筑页的流量视图分为当前意图、最近 30 分钟已完成行程和工作地点，并在地图上显示相应标记与连线。

镜头聚焦支持一次性跳转，也可由用户主动追踪居民或 Pod；不会把镜头位置写回模拟。居民在室内时镜头跟随所在建筑并标注姓名，离开建筑后自动继续跟随室外位置，检查器保持同一居民。新手引导可关闭并记住偏好；首次完成 Pod 接送后自动关闭，设置可重新打开。

城市概览的「清湾」标题下提供「城市增长」滑动开关，直接绑定 `world.growth.enabled`；开启继续新增建筑与后续入驻，关闭则暂停增长，不影响现有居民出行。整行可点，使用原生 checkbox 与 switch 语义；开关状态有文字说明。下方继续显示下一轮片区扩展/旧城填充与剩余时间。建筑显示住户/容量、工作人数/开放岗位或营业率，以及阶段和下一批入驻时间。地图用轻量中心文字和三格进度条表示用途与开发阶段。地图扩展时保留局部视野，仅全城视图随边界扩展；放大下限不随地图无限抬高。关闭的全城居民/车队名册不提前生成全部行 DOM，仍可打开逐人查看。

补助在经济账本中手动领取，没有自动现金补助。城市增长开关已从设置移到城市概览；设置保留安全取消待执行改造、新建城市、本机保存/读取和 JSON 导入/导出。导入先完整验证，载入后保持暂停；下载动作仍需由浏览器确认实际落盘。

# 地图渲染模块

`src/rendering/MapView.tsx` 是只读 React + SVG 地图。它消费 `World` 快照和 `shared/selectors.ts` 的位置结果，不导入模拟模块，也不修改世界状态。

## 视觉约定

- 默认镜头展示完整 64 × 44 世界；建筑网格点是占地中心，边界向外扩 0.4 格。
- 暖白底图只在轨道建设工具下显示点网格。住宅、办公、商店分别使用淡绿、淡蓝、淡赭。
- 相邻轨道在 degree-2 节点合并成带圆角的 SVG 路径；分叉节点才额外显示节点圆点。
- 所选轨道也按整段路径绘制，统一透明度，避免单格端点重叠成圆点；轨道使用非零包围盒的焦点目标与自定义键盘焦点线，禁用浏览器默认的大面积焦点效果。
- 建筑去向标记随缩放保持可读字号，相邻标记自动错开并用细线连接建筑。
- 泊位点、access 点与二者间自动连接分别绘制。Pod 是深青方块，正在上下车或乘车的居民以自身颜色显示在车内，不再重复画人。
- 室内居民不绘制；步行和等候居民的位置全部来自 `residentPosition`，Pod 位置来自 `podPosition`。
- `life` 层保持安静底图；`flow` 层按当前预约资源标出正在占用的轨道。

## 交互契约

- 点击实体调用 `onSelect`；选择居民或 Pod 时，高亮其当前路径。
- 轨道工具点击位置会吸附到合法地图范围内的整数网格。点击泊位时传入的是它独立的 `access` 点。
- 选择工具点击空白取消选择；拖动空白平移，滚轮以指针为中心缩放。双击调用 `onFinishDraft`。
- remove 工具点击轨道只选择 `{ kind: 'track', id }`，实际拆除及安全等待由 App 和模拟负责。
- `focusTarget` 聚焦实体并显示柔和高亮；Pod 追踪持续跟随，手动平移或缩放会退出跟随。

## 测试接口

根 SVG 提供 `data-testid="city-map"`。实体分别提供 `data-building-id`、`data-berth-id`、`data-track-id`、`data-resident-id`、`data-pod-id`；车内乘客点提供 `data-passenger-id`。

地图自身不显示 legend 或工具说明，这些由 UI 模块负责。

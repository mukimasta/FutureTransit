# FutureTransit MVP

FutureTransit 是一个可玩的、双语的城市交通沙盒：居民会在建筑之间步行或乘坐 Pod，玩家铺设 8 方向网格轨道、配置平台与停车位，并观察有限容量下的真实接送。运行时由 React/SVG 界面、TypeScript 模拟和 Web Worker 组成；Worker 拥有唯一的 World 状态。

## 运行

```bash
npm install
npm run dev
```

常用检查：

```bash
npm run typecheck
npm run build
npm test
```

`npm run test:browser` 已保留 Playwright 入口，但当前仓库没有作者测试，不应将其描述为已通过的浏览器验收。

## 已实现的玩法

- 开局仍为 3 栋建筑、24 名居民和 4 辆赠送 Pod；取消四轮结束，交替扩展片区与填充旧城，地图随开发扩展。布局以不规则聚集为主，也有规整组团。
- 建筑分三阶段开放：住宅逐批搬入真实居民，办公楼开放有限岗位，商店营业规模逐步扩大。就业/商业中心加权吸引现有居民，制造跨片区和共享主干需求；不凭空生成客流。
- 居民可步行，或经真实平台接送；Pod 运行在连续轨迹上，而不是固定站点瞬移。没有可用平台、路径、Pod 或停车位时会等待或回退步行。
- 轨道支持 1/2/3 条双向共享车道，没有固定方向车道；不同车道可以并行，但路口仍需协调。每辆 Pod 需要停车位，每个运营连通区额外留一个周转停车位；平台负责上下客，不作为扩车位。
- 新发车计划沿实际路线预约前一段、当前段、后一段的对应车道作为安全缓冲，停站截断；旧存档在途行程保留原预约完成。
- 可暂停、1×/2×/4×运行、暂缓增长、安全排队改造、保存/读取本机存档，以及经过格式验证的 JSON 导入导出。升级与拆除共用整段走廊、⌘/Ctrl 多选、Shift 连选和 Alt 单格选择；拆除先显示数量/退款，再确认批量执行。导出后的实际下载仍需浏览器确认。
- 建筑检查器提供当前意图、最近 30 分钟已完成行程、工作地点、住户名单；流量图层显示对应地图标记与连线。界面提供中文/英文切换。
- 建筑检查器显示住户容量、开放岗位、营业率和下一批入驻时间；地图标注中心与开发阶段。暂缓增长同时暂停新楼和入驻，不停止现有出行。
- 铺轨时移动鼠标预览路径与费用，点击固定端点；非法候选显示红色。居民进楼后追踪建筑，离开后继续跟随。新手引导可关闭，首次完成接送后自动收起，也能从设置重开。

## 经济参数

开局现金 1,900；平台 140、停车位 55、Pod 240、轨道每格 12、每增加一条车道每格 10、票价 4。每 1,800 模拟秒、现金低于 3,000 时开放领取建设补助 280（待领取最多保留一期）；每次增长产生可累计的接入补助 900。两种补助都必须点击预算旁或设置里的“领取补助”，不会自动到账。维护从实际票款中最多承担 20%，超出部分免收；轨道退款按实际支付额 100%，Pod 回售为已支付额 85%（赠送 Pod 退款为 0）。

## 边界与旧版

时间比例为每秒现实时间推进 20 模拟秒，支持 1×/2×/4×；顶栏按 10 分钟显示，1× 下每 30 秒现实时间跳一次，车辆仍连续移动。当前不包含编组、3D、附近建筑平台接驳、自动挑战失败或任意网络死锁证明。增长是时间驱动的，30 分钟稳定性和“持续想玩”仍需进一步试玩验证。

当前技术保护上限为 120 栋建筑、1,200 名逐人模拟居民、160 辆 Pod，地图边长最多 256 格；这不是已经验证的流畅满载承诺，也不宣称无限地图。达到保护边界会提示限制而非结束游戏。旧有限增长存档会保留实体与轨迹并继续发展；大城市自动保存失败时会提醒导出 JSON。

旧版 Demo 与实验仍保留在 Git 的 `main` 和 `demo-v0.1` 中；本目录是新版 MVP。当前工作树的文档和实现尚未创建新的 Git 提交。

更多边界见 [实施契约](docs/IMPLEMENTATION_CONTRACT.md)、[验证记录](docs/VALIDATION.md) 和 [模块文档](docs/modules/)。

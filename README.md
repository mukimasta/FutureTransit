# FutureTransit MVP

当前版本：**MVP v0.0.12** · [更新记录](CHANGELOG.md)。版本沿用 `mvp v0.0.1` 的发布编号，项目配置与锁文件保持一致。

FutureTransit 是一个可玩的、双语的城市交通沙盒：居民会在建筑之间步行或乘坐 Pod，玩家铺设 8 方向网格轨道、配置平台与停车位，并观察有限容量下的真实接送。运行时由 React/SVG 界面、TypeScript 模拟和 Web Worker 组成；Worker 拥有唯一的 World 状态。

它不是汽车模拟器，也不是地铁线路游戏：Pod 是共享的小型无人舱，运行在受控的专用网络中。本楼平台支持室内直达，也可以设置独立站点让附近居民步行接驳；系统自动接送，乘客不换车，你负责设计平台、路网和容量。城市逐渐长大，原本够用的设计会出现新的瓶颈。

## 在线试玩

[打开 FutureTransit](https://mukimasta.github.io/FutureTransit/) — 建议用电脑浏览器，无需安装或登录 GitHub。首次打开会显示中英双语介绍，之后可以在设置里重新查看。

这是单人沙盒，每个人的城市独立保存在自己的浏览器中，不是在线联机或云存档。本地开发地址与线上地址的存档不互通；可在设置中导出 / 导入 JSON 来转移城市。

### 自动发布

向 `mvp` 分支推送后，GitHub Actions 自动构建并发布到 Pages，也可在 Actions 中手动运行 `Deploy game to GitHub Pages`。仓库 Settings → Pages 的 Source 使用 **GitHub Actions**。

`npm run build:pages` 生成带 `/FutureTransit/` 路径的 `dist/`；本地开发仍使用 `npm run dev`，普通构建仍使用 `npm run build`。只上传构建产物，源码和开发依赖不会作为站点文件发布。若更换仓库名称，需要同步更新此命令的路径和试玩链接。

## 轨道流量热力图

左侧「生活 / 流量」切换到流量图层，可选累计或最近 1 个城市小时。每辆 Pod 实际完成一个轨道小段记 1 次，包含空车和载客、两个方向；不计算提前预约，也不等于乘客人数或拥堵率。颜色按当前范围内最繁忙的小段归一化，灰色为零，绿到红表示通过次数增多；点击轨道查看该小段的累计与近期次数。

统计随城市存档保存。旧存档没有逐段历史，从升级后载入时开始记录；界面显示已记录时长。近期窗口按分钟聚合，保留当前分钟及之前 59 分钟（最早边界误差不到 1 分钟），不会无限积累流水。拓宽保留历史；拆除清除该段记录，原地重建重新计数。

## 已实现的玩法

- 开局为 3 栋建筑、24 名居民和 4 辆赠送 Pod；增长交替扩展片区与填充旧城。住宅、办公、商店、学校、医院、餐厅和公园都可成为真实出行目的地。
- 建筑分三阶段开放；居民有工人、学生、教师、医护和服务岗位，产生通勤、上学、就医、用餐与休闲需求，而不凭空生成客流。
- 居民可纯步行、本楼平台室内直达，或实际步行接驳独立/邻楼站点；Pod 运行在连续轨迹上，而不是固定站点瞬移。没有可用平台、路径、Pod 或停车位时会等待或回退步行。
- 轨道支持 1/2/3 条双向共享车道，没有固定方向车道；不同车道可以并行，但路口仍需协调。每辆 Pod 需要专用停车位，不强制额外周转位；平台负责上下客，不作为扩车位。停车位可建在任意合法空地，没有建筑或站点归属，接入同一路网即可调度。
- 新发车计划沿实际路线预约前一段、当前段、后一段的对应车道作为安全缓冲，停站截断。
- 可暂停、1×/2×/4×运行、暂缓增长、保存/读取本机存档，以及经过格式验证的 JSON 导入导出。新建轨道/泊位与拓宽立即生效，已有车辆和乘客继续原行程；仅拆除、移动已有设施需安全排空。升级与拆除共用整段走廊、⌘/Ctrl 多选、Shift 连选和 Alt 单格选择；拆除先显示数量/退款，再确认批量执行。导出后的实际下载仍需浏览器确认。
- 建筑检查器提供当前意图、最近 30 分钟已完成行程、工作地点、住户名单；流量图层显示对应地图标记与连线。界面提供中文/英文切换。
- 建筑检查器显示住户容量、开放岗位、营业率和下一批入驻时间；地图标注中心与开发阶段。暂缓增长同时暂停新楼和入驻，不停止现有出行。
- Tab 切换查看/编辑：查看模式可拖动、缩放、点选查看详情与追踪，但不显示建造、改入口、升级、购售 Pod 或拆除操作；编辑模式点空地、建筑、站点、停车位或已有轨道，都出现「铺轨 / 停车位 / 站点」三个图上按钮。选站点或停车位后，移动鼠标选择方向并预览，点击确认，Esc 返回菜单；不再用方向下拉框。从设施铺轨使用外侧接轨点，从轨道铺轨使用点击处最近的节点。铺轨移动鼠标预览路径与费用，点击固定端点，再点最后端点或按 Enter 建造。非法候选显示红色；拆除直接对选区执行，没有第三种拆除模式。三个按钮至少 84×36 屏幕像素，不随地图缩小。
- 空格全局暂停/继续模拟，不受地图、按钮焦点或查看/编辑模式影响；长按只切换一次，不误触建造/拆除按钮。输入控件、输入法组合状态与介绍弹窗内保留正常键盘行为。
- 点建筑、平台、停车位可在地图旁直接操作；点空地可建独立站点。服务占比与候车人数可点开明细，名单可继续查看居民。居民进楼后追踪建筑，离开后继续跟随。新手引导可关闭，首次完成接送后自动收起，也能从设置重开。

## 经济参数

开局现金 2,600，票价初值为 18/公里（可调 2–60）。Pod 只按实际载客路线里程收费；空驶不收费，但载客和空驶均按 2.4/公里计运行成本。全部轨道、平台、停车位和 Pod 按城市分钟结算维护费，账本保留累计分类和最近 300 笔明细。

补助固定 3 次、每次 1,200，必须手动领取。领完后可借一次 5,000：分 5 期，每个城市日一期，偿还本金 1,000 加本金余额 2% 的利息，按期还清共付利息 300。这是压缩的游戏融资周期，不是现实日利率；可在现金足够时全额提前还款。补助、借款与还本单列为融资现金流，不计入经营利润。

## 边界与旧版

每格为 40 米，统一用于行驶/步行时间、票价、运行费及轨道维护。时间比例为每秒现实时间推进 30 模拟秒，支持 1×/2×/4×；顶栏逐分钟显示，1× 下每 2 秒现实时间推进 1 分钟，车辆仍连续移动。当前不包含编组、3D、普通街道交通、自动挑战失败或任意网络死锁证明。增长是时间驱动的，30 分钟稳定性和“持续想玩”仍需进一步试玩验证。

当前技术保护上限为 120 栋建筑、1,200 名逐人模拟居民、160 辆 Pod，地图边长最多 256 格；这不是已经验证的流畅满载承诺，也不宣称无限地图。达到保护边界会提示限制而非结束游戏。站点版本使用保存键 `futuretransit-mvp-stations-v3`，JSON 信封/World 仍为版本 2。加载上一轮站点存档时仅丢弃停车位旧 `platformId` 标签，不移动或删除设施；更旧版本不迁移。大城市自动保存失败时会提醒导出 JSON。

旧版 Demo 与实验仍保留在本地 Git 的 `main` 和 `demo-v0.1` 中；本目录和线上试玩是 `mvp` 分支的新版 MVP。

更多边界见 [实施契约](docs/IMPLEMENTATION_CONTRACT.md)、[验证记录](docs/VALIDATION.md) 和 [模块文档](docs/modules/)。
